# 설정 오류 사례: 별도 Codex Agent 실행

- `trace.md`: r1 검색·Git 원본 확인·적용과 version 규칙 보류. 당시 테스트 4개.
- `post-update-trace.md`: 새 Codex 세션이 기존 기록을 읽고 r2를 재조회한 뒤 이전 코드를 수정한 결과. 당시 테스트 5개.
- `implementation/`, `tests/`: r2 후속 검증 뒤의 코드와 테스트. 별도 Agent 세션 자체는 실행하지 않는다.

새 세션이 파일을 읽은 실험이며, 동일한 대화 세션의 기억이 자동 갱신된 실험은 아니다. 실제 서로 다른 팀원 계정이나 서버 ACL을 검증하지 않았다.
